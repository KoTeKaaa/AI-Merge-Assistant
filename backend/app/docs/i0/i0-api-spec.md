# I0 — Спецификация REST API и кодов ошибок для фронтенда

> Источник: разделы 4, 5, 6 `team-guide.md`. Маршруты закрепляются в OpenAPI (`FastAPI`); не копируются независимо в frontend. Старые решения (`BackgroundTasks`, OAuth App, `.js` экспорт) запрещены.

---

## Общие правила HTTP

| Код | Значение в контексте сервиса |
|---|---|
| `200` | Успех чтения или изменения |
| `201` | Создание ресурса (не используется для `Run`) |
| `202` | **Создание `Run`** — задание зарегистрировано, но не завершено; фронтенд начинает polling |
| `204` | Успех без тела (например, удаление сессии) |
| `400` | Неверный запрос (невалидный DTO, отсутствующее обязательное поле) |
| `401` | **Без авторизации** — отсутствует или истёк `session_token` / `cookie` |
| `403` | **Отказ без утечки** — чужой ресурс или недостаточно прав; тело содержит только безопасную причину |
| `404` | Ресурс не найден (без раскрытия существования чужих ресурсов) |
| `409` | **Конфликт / устаревший снимок (`stale`)** — `freshness == "stale"` или `execution_state` изменился |
| `422` | Ошибка валидации Pydantic (структурированная) |
| `429` | Превышение квоты (пользовательской или глобальной) |
| `500` | Внутренняя ошибка сервера (без раскрытия секретов) |
| `503` | Сервис временно недоступен (очередь переполнена, sandbox недоступен) |

---

## Единый формат ошибок

Каждый ответ с ошибкой содержит `error_code` из фиксированного набора, различающего модель, окружение, тесты, квоту, права и устаревший снимок.

```json
{
  "schema_version": "T1",
  "error_code": "stale_snapshot",
  "message": "Снимок устарел: target SHA изменился с момента создания прогона.",
  "category": "stale",
  "run_id": "uuid",
  "attempt_id": "uuid",
  "details": {
    "expected_sha": "abc123...",
    "actual_sha": "def456..."
  },
  "safe_reason": "Target branch moved; please refresh and retry."
}
```

### Категории ошибок (`category`)

| Категория | `error_code` | Когда используется |
|---|---|---|
| `model` | `llm_generation_failed`, `invalid_scenario`, `invalid_test_bundle` | Ошибка генерации или валидации сценариев/тестов |
| `environment` | `sandbox_failed`, `build_failed`, `dependency_missing`, `timeout` | Ошибка окружения, сборки, таймаут sandbox |
| `tests` | `test_collection_failed`, `test_execution_failed`, `coverage_report_missing` | Ошибка сбора или выполнения тестов |
| `quota` | `user_quota_exceeded`, `global_queue_full`, `llm_rate_limit` | Превышение квоты пользователя или глобальной очереди |
| `rights` | `forbidden_resource`, `missing_write_permission`, `installation_removed` | Недостаточно прав или установка удалена |
| `stale` | `stale_snapshot`, `stale_target_sha`, `stale_test_bundle` | Устаревший снимок или хеш тестов |

## Маршруты

### `auth`

| Метод | Путь | Описание | Успех | Ошибки |
|---|---|---|---|---|
| `GET` | `/auth/github/login` | Старт входа через GitHub App (редирект, одноразовый `state`) | `302` (редирект) | `401` — неавторизованный запрос к `/auth/*` без сессии |
| `GET` | `/auth/github/callback` | Завершение входа; обмен `state` на сессию | `200` + cookie | `400` — неверный `state`; `403` — `state` использован или истёк |
| `POST` | `/auth/logout` | Удаление сессии | `204` | `401` — нет сессии |
| `GET` | `/auth/me` | Текущий пользователь и установки | `200` | `401` — без авторизации |

**Безопасность:** `state` — одноразовый, привязан к сессии; `cookie` — `HttpOnly`, `Secure`, `SameSite=Lax`; CSRF-токен проверяется на `POST`.

|---|---|---|---|---|
| `GET` | `/repos` | Публичные репозитории пользователя (через GitHub App) | `200` | `401` — без авторизации; `403` — нет прав чтения |

### `runs`

| Метод | Путь | Описание | Успех | Ошибки |
|---|---|---|---|---|
| `POST` | `/runs` | Создание прогона (`Run`) | `202` + `run_id` | `401` — без авторизации; `400` — невалидный DTO; `403` — чужой репозиторий или нет прав записи; `409` — `stale` (если `source_sha`/`target_sha` уже устарели) |
| `GET` | `/runs/{run_id}` | Статус и результат прогона | `200` | `401` — без авторизации; `403` — чужой прогон (без утечки данных); `404` — прогон не найден; `409` — `stale` — `freshness == "stale"` |
| `GET` | `/runs/{run_id}/scenarios` | Сценарии (`ScenarioSet`) | `200` | `401`, `403`, `404` |
| `GET` | `/runs/{run_id}/tests` | Тесты (`TestBundle`) | `200` | `401`, `403`, `404` |
| `GET` | `/runs/{run_id}/coverage` | Покрытие (`CoverageReport`) | `200` | `401`, `403`, `404`; `404` — отчёт отсутствует или повреждён |
| `GET` | `/runs/{run_id}/status` | Краткий статус (для polling фронтенда) | `200` | `401`, `403`, `404`, `409` (`stale`) |

**Правила:** `POST /runs` возвращает `202` сразу после регистрации в БД; LLM/runner не вызываются в HTTP-запросе. Фронтенд опрашивает `/runs/{id}/status`.

### `uploads`

| Метод | Путь | Описание | Успех | Ошибки |
|---|---|---|---|---|
| `POST` | `/uploads` | Загрузка требований (PDF/DOCX/MD) и Python-кода без GitHub | `202` + `upload_id` | `401` — без авторизации; `400` — невалидный файл или размер > 50 страниц / 10 МБ; `403` — квота превышена |
| `GET` | `/uploads/{upload_id}` | Статус обработки загрузки | `200` | `401`, `403`, `404` |

**Безопасность:** загрузка > 50 страниц обрабатывается в фоне (`Celery`); фронтенд получает `202` и опрашивает статус.

### `exports`

| Метод | Путь | Описание | Успех | Ошибки |
|---|---|---|---|---|
| `GET` | `/runs/{run_id}/export` | Экспорт `.feature`, `.py`, ZIP | `200` (файл) или `302` (перенаправление на `volume_path`) | `401` — без авторизации; `403` — чужой прогон или экспорт запрещён; `404` — прогон или артефакт не найден; `409` — `stale` |

**Безопасность:** экспорт содержит только проверенный набор файлов; `.js` запрещён; пути безопасны (без `..`).

---

### `merge`

| Метод | Путь | Описание | Успех | Ошибки |
|---|---|---|---|---|
| `POST` | `/runs/{run_id}/merge` | Намерение пользователя выполнить мерж | `200` или `202` (если в очереди) | `401` — без авторизации; `403` — чужой прогон или нет прав записи; `409` — `stale` (`freshness == "stale"` или `test_bundle_hash` изменился); `422` — условия мержа не выполнены (`verdict != "passed"` или покрытие < 90%) |
| `GET` | `/runs/{run_id}/merge/status` | Статус мержа (`merge_status`) | `200` | `401`, `403`, `404`, `409` |

**Правила:** `MergeDecision` создаётся только сервером; фронтенд передаёт только намерение (`manual` или явное `auto`). Повтор не создаёт дубликат (`reconciliation_id` проверяется через `GitHubAction`).

### `stats`

| Метод | Путь | Описание | Успех | Ошибки |
|---|---|---|---|---|
| `GET` | `/stats` | Агрегаты для дашборда (количество прогонов, среднее покрытие, ошибки по категориям) | `200` | `401` — без авторизации; `403` — чужие данные не включаются в агрегат |
| `GET` | `/stats/runs` | Статистика прогонов пользователя | `200` | `401`, `403` |

### `webhooks`

| Метод | Путь | Описание | Успех | Ошибки |
|---|---|---|---|---|
| `POST` | `/webhooks/github` | Приём webhook от GitHub App | `204` (быстрый ответ) или `202` (если в очереди) | `400` — неверная подпись (`signature_valid == False`); `403` — неверная подпись или неподдерживаемое событие; `409` — `delivery_id` уже обработан (`WebhookDelivery.processed == True`) |

**Безопасность:** HMAC-SHA256 проверяется до JSON-обработки; `delivery_id` проверяется на дедупликацию; неверная подпись не вызывает изменений в БД.

## Формат ошибки `403` (без утечки для чужих ресурсов)

```json
{
  "schema_version": "T1",
  "error_code": "forbidden_resource",
  "message": "Access denied.",
  "category": "rights",
  "safe_reason": "You do not have permission to access this resource.",
  "details": {}
}
```

> **Важно:** тело не содержит `run_id`, `repo_name`, `user_id` или другие данные чужого ресурса. Только безопасная причина.

```json
  "error_code": "unauthorized",
  "message": "Authentication required.",
  "category": "rights",
  "safe_reason": "Please sign in via GitHub to continue."
}
```

## Ограничения и правила интеграции

- **Без `BackgroundTasks`**: все фоновые этапы (`generation`, `validation`, `runner`, `coverage`, `merge`, `webhook`) через `Celery` (`worker/tasks/`).
- **Без OAuth App**: вход через GitHub App (`/auth/github/login` → `callback`); токены не передаются в браузер или sandbox.
- **Без `.js` экспорта**: `/runs/{run_id}/export` возвращает только `.feature`, `.py`, ZIP.
- **Без произвольных команд в runner**: `POST /runs` принимает только фиксированные параметры (`mode`, `environment_profile`, `dependency_profile`); `RunnerJob` не содержит секретов.
- **Без смешивания состояний**: `execution_state`, `verdict`, `freshness`, `merge_status` — отдельные поля; фронтенд отображает их раздельно.
- **Без ложного 100%**: при нулевом знаменателе (`executable_changed_lines == 0`) `coverage_percentage` — `null`; фронтенд показывает `N/A`, не `100%`.
